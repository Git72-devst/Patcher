PATCHER 1.1.0 — локальная подготовка релиза, 23.10.2026

Новый интерфейс Bento со встроенным Inter и SVG-значками. Проверка обновлений
перенесена на главный экран. Обновление PATCHER после скачивания применяется
явным нажатием «Перезапустить»; установщик XiaomiPCManager запускается вручную.

Переработаны установка и отображение её этапов: проверка файлов, распаковка,
прогресс и оценка оставшегося времени. Тяжёлые операции вынесены из потока UI.
Завершение и предложение перезапустить Проводник показаны в основной карточке.
Это перезапуск explorer.exe, не перезагрузка компьютера; несохранённые документы
не восстанавливаются. Проверки файлов и восстановление закрытых программ сохранены.

Обновлены таблица логов, карточки истории версий, «Слова автора», выпадающие
списки тем и версий, прокрутка и QR-коды. После успешной обычной установки
удаляется временный кэш выбранной версии.

Четыре архива переводов обновлены из актуальных Patcher_F_archive:
5.8.0.74, 5.8.0.95, 5.8.1.121 и 5.8.1.130.
Каждый файл сверён по SHA256 с исходной папкой, проверены CRC и неизменность
исходников во время упаковки. Новые хеши и размеры записаны в index/manifest.
Исторические SHA256SUMS не изменялись. ZIP в GitHub Desktop не копируются.

Автообновление: patcher/Patcher-1.1.0.exe, type="exe", без arguments.
SHA256: 03a702b8f1ab7f06c850f077efd0d01fec54624273c5e01e266516a6593326aa
Размер: 7439360 байт.
Обычный EXE не является полным автономным пакетом. Для ручной установки
используйте Patcher-1.1.0-sfx.exe либо Patcher-1.1.0-portable.zip с библиотеками.
Production Release: demo/preview/recording/showcase/test-флаги выключены,
manifest requireAdministrator проверен. Цифровая подпись не добавлялась.

Сопутствующие файлы: SHA256SUMS-1.1.0.txt и
SHA256SUMS-translations-2026-10-23.txt. Первые хеши описывают пять файлов
в patcher/, которые копируются отдельно из проверенного release package.

Публикация НЕ выполнена. Перед публикацией метаданных нужно заменить четыре
ZIP из github-server/archives в GitHub Release с тегом archives. Иначе клиенты
получат прежние ZIP, не соответствующие новым SHA256. GitHub Desktop не загружает
Release assets автоматически. Коммит, push и upload этим helper не выполняются.
maintenance.json, каталог установщиков и исторический LFS ZIP не изменяются.
