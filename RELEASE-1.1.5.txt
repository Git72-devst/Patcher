PATCHER 1.1.5 — 14.11.2026

Исправления установки перевода

- Компоненты выбранной версии XiaomiPCManager останавливаются после
  проверки пакета, непосредственно перед заменой файлов. Если файлы уже
  актуальны, останавливать компоненты не нужно.
- Для MAFSvr.exe предусмотрено адресное завершение оставшегося процесса
  после подтверждённой остановки службы Windows. Оно разрешается только
  для проверенного исходного процесса отдельной службы по точному пути
  выбранной версии. Восстановление выполняется через диспетчер служб.
- Для XiaomiPCManager 6.0.2.19 и новее PATCHER ищет MiDropShellExt.dll
  в MiSmartShare. Проводник закрывается только с согласия пользователя;
  перед закрытием проверяется, что найден тот же процесс.
- При Win32 109 PATCHER уточняет состояние службы в диспетчере служб.
  Если исходная служба остановлена и её процесс завершился, установка
  продолжается. Код 109 не разрешает принудительное завершение.
- Если XiaomiClipboard.exe или другой компонент завершился во время
  подготовки к закрытию, PATCHER перепроверяет исходный процесс и
  сохраняет данные для его восстановления. Если завершение не подтверждено,
  файлы не заменяются, а журнал указывает конкретный этап сбоя.
- Уточнены сообщения о восстановлении служб: успешный запуск каждого
  компонента отражается отдельно, при тайм-ауте указывается состояние SCM.

Переводы

Обновлены оба архива XiaomiPCManager 6.0.2.30: 6.0.2.30.zip (русский)
и 6.0.2.30_en.zip (английский). Архив выбирается по версии и языку.
Пакеты 6.0.2.19 и каталог установщиков не менялись.
В каждом обновлённом ZIP по 1027 файлов. Проверены CRC, структура Rus/
и SHA256 каждого распакованного файла. Суммы архивов указаны в
SHA256SUMS-translations-2026-11-14.txt.

Проверка и публикация

Пользователь подтвердил успешную установку в проверочной сборке, в которую
вошли все перечисленные исправления. Релиз 1.1.5 собран с включёнными
защитами, без демо- и тестовых режимов. Файлы самообновления проверяются
по размеру и SHA256; русская и английская история изменений читаются
с сервера, как и в 1.1.4.

Прошёл 51 из 51 автотестов. SFX и portable ZIP проверены по CRC;
SHA256 всех 172 файлов совпали после распаковки. Готовые пакеты находятся
в D:/Work/Mi/Patcher/exports/Patcher-1.1.5-verified-20261114.

Для самообновления используется patcher/Patcher-1.1.5.exe. Полные пакеты
для ручной установки — Patcher-1.1.5-sfx.exe и Patcher-1.1.5-portable.zip.
Контрольные суммы сборки: SHA256SUMS-1.1.5.txt.

Перед отправкой коммита замените оба одноимённых ZIP 6.0.2.30 в GitHub
Release с тегом archives, затем сверьте SHA256 и размеры опубликованных
файлов с каталогами 1.1.5. Архивы переводов не входят в обычный Git-коммит.
Публикация архивов и отправка коммита выполняются отдельно.
