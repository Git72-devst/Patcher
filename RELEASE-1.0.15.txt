PATCHER 1.0.15 — исправление самообновления, 13.10.2026

Автоматическое обновление:
patcher/Patcher-1.0.15.exe — обычный EXE, не самораспаковывающийся архив.
index.json, manifest.json и patcher/latest.json указывают type="exe",
SHA256 именно этого файла и не содержат SFX arguments.

Это обеспечивает переход с 1.0.12: старый механизм копирует скачанный
EXE поверх Patcher.exe в папке запущенной программы и запускает его
из той же папки. Не заменяйте этот файл SFX под тем же именем и не
меняйте type на sfx: старый 1.0.12 неверно заключает SFX-ключи в кавычки.

Полная ручная установка:
patcher/Patcher-1.0.15-sfx.exe — распаковывает файлы в соседнюю папку
PATCHER и запускает программу;
patcher/Patcher-1.0.15.7z — полный набор файлов без SFX-модуля;
patcher/Patcher-1.0.15-sfx-config.txt — конфигурация упаковки.

Зависимости обычного EXE совместимы с пакетом 1.0.12; проверенные
Qt и MSVC runtime DLL совпадают. Автоматическое обновление не меняет
расположение программы и не заменяет эти зависимости.

Коммит, пуш и загрузка файлов в GitHub не выполняются автоматически.
Прежде чем публиковать новые JSON, опубликуйте файл Patcher-1.0.15.exe
по подготовленному адресу в ветке main.

Проверки пройдены: четыре регрессионных набора; безопасное воспроизведение
старого сценария 1.0.12; замена и единственный запуск EXE из исходной
папки; пути с пробелами, кириллицей, %TEMP%, &, ^, ! и скобками;
ожидание в скрытом процессе и повтор копирования заблокированного EXE.
Ручной SFX проверен без запуска настоящего PATCHER: все 37 файлов
после распаковки побайтно соответствуют готовой папке программы.

Если неудачное обновление уже запустило копию из Temp\PATCHER:
1. Закройте эту временную копию.
2. Запустите прежний PATCHER 1.0.12 из исходной папки.
3. После публикации обновлённых метаданных повторите обновление.
Обновление из работающей временной копии закономерно изменит именно
её папку: надёжно определить прежнюю исходную папку из неё нельзя.

SFX использует modified 7zSD 1.7.0.3900 All x64. Лицензии и авторские
уведомления входят в пакет, соответствующий исходный архив находится
в patcher/7zsd_src_170_3900.7z. Изменён только requireAdministrator
в Windows PE manifest модуля.
