PATCHER 1.1.1 — локальная подготовка релиза, 07.11.2026

Добавлена поддержка XiaomiPCManager 6.0.2.19: русский и английский переводы
поставляются отдельными архивами. Выбранный язык учитывается при загрузке,
предзагрузке и установке. Недоступный язык нельзя выбрать.
Для версий начиная с 6.0.2.19 скрыты модули камеры и темы и убран автоматический
переход к патчу камеры после установки предзагруженного перевода.

Добавлены язык интерфейса PATCHER (системный, русский, English), английская
история изменений с GitHub, подготовка патча установки и красный индикатор
неподдерживаемой версии. Обслуживание определяется только абсолютной датой
expectedEnd и автоматически снимается после её наступления.

Новые архивы для Release с тегом archives:
  archives/6.0.2.19.zip — русский перевод
  archives/6.0.2.19_en.zip — английский перевод
Архивы обоих языков имеют внутренний каталог Rus для совместимости установщика;
это техническое имя модуля, а не указание языка содержимого.

  Размер: 38336 байт

DLL и установщик скачиваются только в папку «Патч установки» рядом с PATCHER.
PATCHER не запускает установщик автоматически и не копирует DLL в System32.

Место загрузки новых ZIP и установщика:
  https://github.com/Git72-devst/Patcher/releases/edit/archives
В разделе Assets прикрепите файлы с точными именами, указанными выше.
Сначала загрузите Release assets, затем публикуйте коммит с index/manifest.
GitHub Desktop не загружает Release assets при обычном commit/push.

предзагрузку, установку в изолированные тестовые папки и интерфейс 100/150/200%.
