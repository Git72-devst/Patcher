# Установщики и патч установки

Установщики прикрепляются к существующему GitHub Release с тегом `archives`:

[Открыть редактирование Release и раздел Assets](https://github.com/Git72-devst/Patcher/releases/edit/archives).

Фактическое имя уже опубликованного asset XiaomiPCManager 6.0.2.19:

`_6.0.2.19_c379be90.exe`

[Скачать установщик](https://github.com/Git72-devst/Patcher/releases/download/archives/_6.0.2.19_c379be90.exe).

GitHub нормализовал имя при загрузке, убрав китайские символы. В каталоге
нужно указывать фактическое имя asset, а не исходное имя локального файла.
Иначе сервер возвращает 404, даже если установщик уже есть в Release.

Исходный файл: `A:/LIQALRT86/Downloads/Telegram Desktop/小米电脑管家_6.0.2.19_c379be90.exe`.
Размер — `832749856` байт. SHA256:

```text
d520fae7b3f1df35bc20ff87e314aa7417bad8cbfd8e5181cab4796f005f4d1a
```

В том же Release опубликованы `6.0.2.19.zip` и `6.0.2.19_en.zip`; локальные копии
подготовлены в `D:/Work/Mi/Patcher/github-server/archives`. Имена и размеры
проверяются по фактическому списку assets. При следующих обновлениях сначала
загрузите файлы и проверьте их итоговые имена, затем делайте push метаданных,
чтобы клиенты не получили неверные ссылки. ZIP и установщик не нужно добавлять
в обычный Git-коммит.

`msimg32.dll` — отдельный файл патча установки. Он находится в этой папке
репозитория и скачивается по Raw-ссылке, указанной в `index.json`. Его можно
добавлять в обычный коммит; переносить в GitHub Release не требуется.

При подготовке патча PATCHER скачивает DLL и самый новый установщик в папку
«Патч установки» рядом с программой. Файлы проверяются по размеру и SHA256.
Установщик автоматически не запускается; DLL в системные папки не копируется.
