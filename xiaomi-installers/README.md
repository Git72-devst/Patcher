# Установщики и патч установки

Новый установщик нужно прикрепить к существующему GitHub Release с тегом `archives`:

[Открыть редактирование Release и раздел Assets](https://github.com/Git72-devst/Patcher/releases/edit/archives).

Для XiaomiPCManager 6.0.2.19 загрузите файл с точным именем:

`小米电脑管家_6.0.2.19_c379be90.exe`

Исходный файл: `A:/LIQALRT86/Downloads/Telegram Desktop/小米电脑管家_6.0.2.19_c379be90.exe`.
Размер — `832749856` байт. SHA256:

```text
d520fae7b3f1df35bc20ff87e314aa7417bad8cbfd8e5181cab4796f005f4d1a
```

В тот же Release загрузите `6.0.2.19.zip` и `6.0.2.19_en.zip` из
`D:/Work/Mi/Patcher/github-server/archives`. Имена должны совпадать с каталогом.
Сначала загрузите эти три файла, затем делайте push метаданных, чтобы клиенты
не получили ссылки на ещё не опубликованные assets. ZIP и установщик не нужно
добавлять в обычный Git-коммит.

`msimg32.dll` — отдельный файл патча установки. Он находится в этой папке
репозитория и скачивается по Raw-ссылке, указанной в `index.json`. Его можно
добавлять в обычный коммит; переносить в GitHub Release не требуется.

При подготовке патча PATCHER скачивает DLL и самый новый установщик в папку
«Патч установки» рядом с программой. Файлы проверяются по размеру и SHA256.
Установщик автоматически не запускается; DLL в системные папки не копируется.
