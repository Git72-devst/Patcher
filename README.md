# Patcher
Патчи и переводы для XiaomiPCManager.

## PATCHER 1.1.1

Добавлена поддержка XiaomiPCManager 6.0.2.19 с русским и английским переводами.
История изменений: [русский](changelog.json), [English](changelog.en.json).
Начиная с 6.0.2.19 модули камеры и темы не отображаются; перевод устанавливается
без автоматического перехода к патчу камеры.

Новый установщик и два ZIP перевода загружаются в Assets существующего
[Release archives](https://github.com/Git72-devst/Patcher/releases/edit/archives),
не в обычный Git-коммит. Подробности и контрольные суммы — в
[инструкции](xiaomi-installers/README.md) и [описании релиза](RELEASE-1.1.1.txt).
Сначала загрузите Assets, затем отправляйте коммит метаданных через GitHub Desktop.

Обслуживание включается только при будущей абсолютной дате `expectedEnd`
в `maintenance.json`, например `2026-11-07T18:30:00+03:00`.
После наступления этой даты интерфейс разблокируется автоматически.
Пустая/неверная/прошедшая дата не включает обслуживание; флаги yes/no не нужны.
