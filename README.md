# Patcher
Патчи и переводы для XiaomiPCManager.

## PATCHER 1.1.5

Исправлены остановка и восстановление компонентов XiaomiPCManager, обработка
самостоятельного выхода `XiaomiClipboard.exe` и освобождение вложенной
`MiDropShellExt.dll`. Проводник закрывается только после подтверждения.

Обновлены архивы RU и EN для XiaomiPCManager 6.0.2.30. Перед push метаданных
замените оба ZIP в Release `archives`. См. [описание релиза](RELEASE-1.1.5.txt)
и [инструкцию](archives/README.md).

## PATCHER 1.1.4

Исправлена преждевременная отмена установки перевода, когда служба остановилась,
но процесс `MAFSvr.exe` ещё завершался. PATCHER останавливает компоненты выбранной
версии и ждёт выхода процессов служб до 10 секунд на проход. При тайм-ауте файлы
не заменяются, а остановленные службы восстанавливаются.

Обновлены переводы RU/EN для XiaomiPCManager 6.0.2.19 и добавлены оба языка для
6.0.2.30. Все четыре ZIP опубликованы в Release `archives`. В каталог добавлен
установщик 6.0.2.30 — `_6.0.2.30_acb3c61c.exe`. См. [инструкцию](archives/README.md) и
[описание релиза](RELEASE-1.1.4.txt).

## PATCHER 1.1.3

Обслуживание проверяется каждые 10 секунд независимо от текущего режима.
Обычная кнопка проверки также сначала перечитывает `maintenance.json`.
Фоновые запросы не мигают в интерфейсе и не дублируют одинаковые записи журнала.
Уточнена обработка SCM-служб MiPlayCastService и MiRemoteDeskService.

Обновлены RU/EN архивы XiaomiPCManager 6.0.2.19.

## Исправления 1.1.2

Исправлена установка при занятых файлах XiaomiPCManager, включая Continuity
Service: процессы выбираются по пути внутри папки выбранной версии, службы
останавливаются и запускаются через диспетчер служб Windows. После установки,
ошибки или отмены восстанавливаются только ранее закрытые PATCHER компоненты.
Если остановка не удалась, замена файлов отменяется; при ошибке обратного запуска
доступна повторная попытка. Также исправлена ссылка установщика 6.0.2.19 на GitHub.

## Возможности 1.1.1

Добавлена поддержка XiaomiPCManager 6.0.2.19 с русским и английским переводами.
История изменений: [русский](changelog.json), [English](changelog.en.json).
Начиная с 6.0.2.19 модули камеры и темы не отображаются; перевод устанавливается
без автоматического перехода к патчу камеры.

Новый установщик и два ZIP перевода загружаются в Assets существующего
[Release archives](https://github.com/Git72-devst/Patcher/releases/edit/archives),
не в обычный Git-коммит. Подробности и контрольные суммы — в
[инструкции](xiaomi-installers/README.md).
Сначала загрузите Assets, затем отправляйте коммит метаданных через GitHub Desktop.

Обслуживание включается только при будущей абсолютной дате `expectedEnd`
в `maintenance.json`, например `2026-11-07T18:30:00+03:00`.
После наступления этой даты интерфейс разблокируется автоматически.
Пустая/неверная/прошедшая дата не включает обслуживание; флаги yes/no не нужны.
